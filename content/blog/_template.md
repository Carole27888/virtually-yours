HOW TO USE THIS TEMPLATE (delete these notes before publishing)
1. Copy this file and rename the copy, using lowercase words and hyphens.
   The file name becomes the web address:
   how-to-delegate-email.md  ->  /blog/how-to-delegate-email
2. Fill in the details between the --- lines at the top:
   - date: the day the post goes live (YYYY-MM-DD). A future date
     schedules the post. It stays hidden until that day.
   - category: keep to a few, for example Delegation, Systems,
     Productivity, Hiring, Growth.
   - draft: true hides the post. Delete that line when it is ready.
3. Length: aim for 1,000 to 1,500 words. Posts under 600 words get a
   warning when the site builds, because short pages rarely rank.
4. Files starting with _ (like this one) are never published.

Start with two or three sentences that tell the reader what they will get from the post.

## Use a heading for each main point

Write in short paragraphs. Leave a blank line between paragraphs.

### A smaller heading inside a section

- Another bullet point

1. Numbered step
2. Next step
